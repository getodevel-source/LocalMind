## Prioritised fix list (no fixes applied)

**P0 — user-visible breakage**
1. Unclosed `<div>` in Panel launcher card swallows all six sibling tabs (`ui.html` served ~line 1597: `<div class="profile-hint" data-i18n="launch.effortHint">…</div>` is followed by `<div class="field-group">` for the agent selector with no intervening close — the effort row/`cli-access-box` nesting leaves `delta=+1` across the dashboard range; the browser reparents `#tab-chat…#tab-settings` inside `#tab-dashboard`, so only Panel paints). Suspect: `ui.html:1582-1600` (effort-hint/agent-selector region). Fix: close the dangling div; verify `div opens == closes` and every tab paints.
2. Missing i18n `launch.defaultFolder` (es+en) — raw key rendered under the folder picker. Suspect: dict blocks `ui.html:~2158/~2362` (key absent though `T('launch.defaultFolder')` + `data-i18n` both reference it). Fix: add es `(Ubicación predeterminada)` / en `(Default location)`.
3. Missing i18n `launch.cliDesc` (es+en) — raw key prefix in agent hint (`launch.cliDesc…localmind/…`). Suspect: dict blocks (keys `launch.ompDesc`/`launch.piDesc` were removed in the Orca purge but `updateLauncherHint` still calls `T('launch.cliDesc')`). Fix: add es `Sesión CLI conectada a ` / en `CLI session connected to `.

**P1 — wrong/stale content**
4. Launcher selector has no `opencode` agent though `GET /api/agents` serves it (`pi,omp,opencode,web,deepseek`, all available). Suspect: `launcherFallbackAgents()` + option rendering in `ui.html:~3700-3760`. Fix: render served list generically (already does) + extend fallback/static labels + i18n if a hardcoded list exists.
5. Ajustes hides `start_cooldown_secs`, `max_starts_per_hour`, `power_safe`, `slow_gate_tps` (all live in TOML, none shown). Suspect: settings cards `ui.html:~1930-2060` + `renderAppConfig`. Fix (confirm scope first): read-only display or editable controls per contract.
6. Version badge shows `local` because `/api/version` has no `version` field (`{"app":"2.0.0",…}`). Not a UI bug (truthful fallback), but confirm whether the backend should expose `version` or the UI should read `app`.

**P2 — polish / verify-later**
7. Duplicated launcher hint: `launch.effortHint` and the agent hint both render adjacent helper lines under the Panel launcher (fine, but visually noisy) — `ui.html:1597` + `#launcher-agent-hint`.
8. Error-banner path unverified (invalid start was accepted; cooldown 400 seen only via curl). Exercise `renderStatus({status:'error',…})` + a 400 on save with the banner visible.
9. Docs drift: `docs/SRS.md` LM-MOT-6 says default 5400 s/90 min; live TOML+API say 1500 s. Docs-side fix, out of UI scope.
10. Profile fallback labels carry emoji (⚡📚📖🌌, `ui.html:~2879-2888`) while the brand purge removed emoji elsewhere — intentional or leftover, owner's call.
